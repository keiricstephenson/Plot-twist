# Plot Twist 🎬

Get from one movie to another using only "More like this" links. How fast can you hop?

- **Daily challenge:** everyone gets the same start and goal each day.
- **Random:** Easy, Medium or Hard.
- **Par:** the number of hops in a route that's known to work. Can you beat it?

## Setup

1. Get a free API key from [TMDB](https://www.themoviedb.org/settings/api) (choose "Developer").
2. Open `index.html` and paste the key into the line near the top:
   ```js
   const TMDB_KEY = "your-key-here";
   ```
3. Host it anywhere static. GitHub Pages works: **Settings → Pages → Deploy from a branch → main / (root)**.
